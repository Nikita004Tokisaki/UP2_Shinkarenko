# УП.02. Разработка программного обеспечения

## Описание проекта
WPF-приложение для управления пользователями: авторизация, регистрация,
CRUD-операции, поиск, фильтрация, сортировка.

## Технологии
- C# / WPF (.NET Framework)
- Entity Framework (ADO.NET Entity Data Model)
- Microsoft SQL Server
- SHA-1 (хеширование паролей)

## Структура проекта
- App.xaml — подключение словаря стилей
- Dictionary.xaml — словарь стилей
- MainWindow.xaml(.cs) — главное окно
- Model — модель Entity Framework
- Pages/ — страницы приложения
- Resources/ — изображения

## Запуск
1. Открыть решение в Visual Studio.
2. Восстановить пакеты NuGet (EntityFramework, EntityFramework.SqlServer).
3. Проверить строку подключения в App.config.
4. Запустить проект (F5).
